# Bug audit of v1.10.13 — main-1

Reviewed upstream commit `9f62bb5`. This is a bug-fix revision of that patch; cultivation rank mappings, retraining penalties and the HC source remain intact. The audit combines the full regression suite, targeted reproductions, real mobile browser checks and native simulation. It cannot establish that every possible game state is bug-free.

## Fixed behavior

1. Basic herb gathering no longer chooses basic herbs in dangerous zones. Beginners also avoid unsafe ore/other-resource destinations. Candidate routes to basic herbs must stay inside the sect or its protected collection approach.
2. The shared safe-belt predicate now covers the two-tile approach immediately outside the south gate (`y0=132`), and the gathering module uses that same predicate. This prevents a nominally safe walk from crossing an unprotected gap.
3. Resource placement checks an actual navigable path from the gate instead of accepting any unblocked tile, which could include isolated islands.
4. Every beast spawn, including the dedicated legendary zone, validates safe-belt exclusion and passable outdoor land. Placement and fallback stay bounded inside the original habitat.
5. Failed movement or failed action start releases the resource lease immediately through the existing cancellation path.
6. Gathering retention considers both carried recipe scrolls (`n.inv.recipes`) and already learned personal recipes (`n.recipes`).
7. Two fortune alchemy trials use the actual `ALCHEMY` proficiency, including valid practice on an insight reward. Previously lowercase `alchemy` caused the learned skill to be ignored.
8. Material donations reject zero, negative, fractional, nonfinite and string quantities, as well as unknown material IDs, without consuming inventory or minting CP.
9. Beginner gathering preferences use cultivation world rank rather than the unrelated sect title rank.
10. At least eight of the existing 48 resource slots remain available to safe-belt nodes. Otherwise untouched dangerous nodes eventually blocked all safe herb replenishment. No item is removed to make room and the total cap is unchanged.
11. `BASIC_HERB` and `OTHER_HERB` now render as plants with material-specific petals. They previously fell through to the generic brown material sprite despite valid simulation data.

`test/outside_audit.js` contains the targeted reproductions, plus real gathering settlement across a mid-action save/load and a duplicate-completion check. `test/outside_visual_browser.js` tests actual Canvas pixels, not just source text. Every repaired defect was reproduced before its fix.

## Verification

- **50/50 test groups passed**, including syntax checks of **112 JavaScript files**. Full regression results: [`assertions.json`](../test/results/assertions.json). Includes browser/mobile layout, controls, panels, save/load, speeds through 48x, 80-NPC performance, combat, crafting, economy, offices, knowledge, retraining, ecology, rank pools and the new regressions.
- Both `index.html` and rebuilt `JianghuSect_single.html` booted at 412×860 with 48 resource nodes, no horizontal overflow and no page errors; UI inspection did not advance simulation RNG.
- Native simulation: **360 game days / 518,400 ticks**, seed `audit-release-2026-10-29`, with a mid-run save/load. Resource ownership, stock, HP/CP finiteness, resource cap, wildlife cap, legendary concurrency and safe-belt invariants passed.
- Observed **10,368** successful finite harvests/units, **6,638.9 CP** from their donations, **506** basic pills crafted, **105** pill purchases and **367** pill applications. Purchases/applications include all pill types; they are not a claim that every crafted basic pill was bought or consumed.
- Observed **31** fortune departures and **19** realm departures, all rank 1 in this seed. Higher-rank mapping and committed pools are covered by controlled tests; natural higher-rank participation was not observed.
- Observed **13** legendary appearances over the run, with peak active wildlife **11/12** and at most one legend alive concurrently. Ordinary refill batches of 1, 2 and 3 were observed.
- **Zero natural private retentions** in this seed. The repaired retention branch works in controlled tests, but natural personal-production incentives need design work; this is explicitly recorded for the next patch.
- Human core fingerprint remains `155:2f9c9dd7`; the source file was not edited.

The long simulation observer now records successful production APIs and returns wrapped results unchanged. Previously several published metric fields stayed zero because they were never connected to events. The resource economy integration test now actually consumes donated herbs through brewing, buys a resulting pill and verifies healing and unit consumption.

Complete simulation data: [`outside_audit_360d.json`](../test/results/outside_audit_360d.json).
