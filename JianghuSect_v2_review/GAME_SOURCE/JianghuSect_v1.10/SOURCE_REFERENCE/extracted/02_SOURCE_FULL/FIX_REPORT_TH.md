# Jianghu 2.08.2 — EP.5 Runtime Fix + Speed ×16

## บั๊กที่พบจากรายงานผู้เล่น

- `renderHero()` อ่าน `p.needs.hunger` โดยตรง แต่เซฟจริงมี NPC 24/39 ตัวที่ไม่มี `stageLocal.needs`; จึงหยุดระหว่าง EP.5

## สิ่งที่แก้

- เพิ่ม migration ตอนโหลดเซฟ: เติม `hunger:20`, `social:25`, `safety:10` เฉพาะฟิลด์ที่ขาดหรือไม่ใช่ตัวเลข
- เพิ่มค่าเริ่มต้นให้ NPC ใหม่ทุกชนิดที่สร้างผ่านสมาชิก/บริการ/โจร และป้องกันหน้าแฟ้มด้วย optional chaining
- รักษาเซฟ schema รุ่น 11; ไม่เปลี่ยน tick, episode, inventory, identity หรือข้อมูลความคืบหน้าอื่น
- เพิ่มความเร็ว ×8 และ ×16, ปรับ catch-up loop และแก้ floating-point boundary

## ตรวจยืนยัน

- โหลดเซฟจริงจาก `Jianghu_Runtime_Report_v2_08.json` ผ่าน และคง tick/episode เดิม
- regression test ที่จำลอง NPC ไม่มี needs และ needs บางส่วนผ่าน
- UI harness ที่เปิดแฟ้ม NPC ที่ไม่มี needs ผ่าน
- speed unit tests และการเดิน simulation จริงที่ ×16 ผ่าน
- ยังต้องให้ลูกพี่ทดลองบน Android จริงเพื่อประเมินความลื่นและความร้อน

# Jianghu 2.08.1 — Hotfix + Slim Source

## จุดผิดพลาดที่ยืนยันก่อนแก้ด้วย Frontier จริง

1. **โรงหลอมแอบใช้ของที่ขึ้นชั้นร้านค้า:** ตั้ง `storeCount=count` ทั้งหมด แต่ `canCraftForSect` ยังตอบว่าหลอมได้ และ `craftForSect` หักของไป 2 หน่วยจริง เพราะนับสต็อกทั้งคลังและร้านรวมกัน
2. **ขายของให้พ่อค้าที่เงินหมดแล้วยังได้เงิน:** ทำให้หินวิญญาณพ่อค้าเหลือ 0 แล้วสำนักยังขายของได้และได้เงิน +5 หินวิญญาณ โดยการหักเงินพ่อค้าล้มเหลวและไม่มีการตรวจผล
3. **มติอัปเกรดเปรียบเทียบเงินกับผลรวมเงิน+ไม้+แร่:** กฎงบไม่เกิน 25% เอาต้นทุนต่างหน่วยมาบวกกัน ทำให้ปฏิเสธโครงการที่จ่ายได้จริง
4. **วัตถุดิบหายากชิ้นสุดท้ายถูกย้ายขึ้นร้านอัตโนมัติ:** แม้ศิษย์รู้สูตรและมีโรงหลอมอยู่แล้ว ระบบยังขายของชิ้นสุดท้าย ทำให้หลอมไม่ได้
5. **คำสั่งขายจำนวนเศษถูกปัดลงโดยเงียบ:** เช่น 1.5 กลายเป็น 1 หน่วย แทนที่จะปฏิเสธข้อมูลไม่ถูกต้อง

## การแก้ไข

- โรงหลอมตรวจวัตถุดิบที่ยังไม่วางขาย (treasury-only) และรวมความต้องการของสูตรที่ใช้วัตถุดิบชนิดเดียวกันหลายบรรทัด ก่อนเริ่มหัก; ป้องกันหักบางส่วนโดยไม่ตั้งใจ; UI แสดงจำนวนวัตถุดิบสำหรับหลอมที่ใช้ได้จริง
- การจัดร้านกันวัตถุดิบหายากอย่างน้อยหนึ่งชุดสำหรับสูตรที่ศิษย์เรียนรู้และมีโรงหลอมรองรับ ไม่ย้ายชิ้นสุดท้ายขึ้นร้านโดยอัตโนมัติ
- ใบสั่งซื้อเช็กยอดเงินในกระเป๋าพ่อค้าจริงและวงเงินใบสั่งซื้อพร้อมกัน; หักเงินพ่อค้าก่อนจ่ายให้สำนัก พร้อมคืนเงินถ้าฝากของไม่สำเร็จ; ปฏิเสธจำนวนเศษ
- อัปเกรดใช้เกณฑ์ 25% เฉพาะหินวิญญาณ; ไม้/แร่มีเกณฑ์สำรองแยกต่างหาก
- ย้าย base64 ฟอนต์และ atlas ที่มีอยู่แล้วออกจาก CSS กลับไปอ้างไฟล์ `assets` (ลด CSS ~3,040,057 เหลือ ~44,839 อักขระ); HTML เล่นเดี่ยวประกอบกลับแบบออฟไลน์
- ตัด ZIP ซ้อน, HTML ซ้ำ, ภาพต้นฉบับ PNG, หลักฐานทดสอบและแพตช์เก่าออกจาก **แพ็กเกจซอร์สสำหรับ AI** แต่ไม่ลบระบบรันไทม์
