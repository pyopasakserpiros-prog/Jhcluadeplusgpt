# ผลตรวจและแก้บั๊ก — 28 ตุลาคม 2026

แตกเกมจาก `JianghuSect_v1-10-9.zip` เป็น `JianghuSect_v1.10/` และรักษา ZIP ต้นฉบับไว้ ไม่แก้แกนมนุษย์ `js/human_core.js`

## บั๊กเกมที่ยืนยันและแก้แล้ว

- **การยกเลิกสัมผัสถูกนับเป็นการแตะ:** `pointercancel` ไม่ยกเลิกการเลือก NPC/โหมดติดตามหรือเปิดเป้าหมายบนแผนที่อีกต่อไป
- **มินิแมปค้างในโหมดลาก:** หยุดลากเมื่อสัมผัสถูกยกเลิกหรือเสีย pointer capture
- **แตะสองนิ้วแล้วเกิด single tap:** ป้องกันการเลือก/ยกเลิกเป้าหมายโดยไม่ตั้งใจ แม้สองนิ้วไม่ขยับ
- **กู้คืนหลังข้อผิดพลาดแล้วหยุดเกมไม่ได้ในครั้งถัดไป:** ล้างสถานะข้อผิดพลาดเมื่อโหลดหรือสร้างโลกสำเร็จ ทำให้ข้อผิดพลาดครั้งใหม่หยุดเวลาและแจ้งเตือนได้
- **โหลดเซฟที่หยุดเวลาแล้วกลับเดินต่อ:** รักษาความเร็ว 0 และความเร็วของเซฟเก่าที่ไม่มี `runtimeTiming` ทั้งในตัวอ่านเซฟและตัวผูกโลกเข้าหน้าจอ
- **เซฟเสียเปลี่ยนนาฬิกาโลกปัจจุบันแม้โหลดไม่สำเร็จ:** ตรวจโครงสร้างหลักก่อนสร้างโลก และคืน HC/STATS clocks หากการสร้าง/ย้ายข้อมูลล้มเหลว ปฏิเสธเวลาที่ใช้ไม่ได้ สถานะ RNG ไม่ครบ ID ตัวละครซ้ำ และฟิลด์หลักที่ขาดจนทำให้เกมพังภายหลัง
- **เมนูโหลดก่อนเริ่มเกมเปิดคำสั่งที่ต้องมีโลก:** แสดงเฉพาะโหลด/นำเข้า และกลับสู่ผู้สมัครชุดเดิมเมื่อปิด หลีกเลี่ยงปุ่มส่งออก/เครื่องมือ/เกี่ยวกับที่เคยทำให้เกิดข้อผิดพลาดเมื่อโลกเป็น null
- **นำเข้าเซฟสำเร็จแต่หน้าเลือกเจ้าสำนักบังเกม:** ซ่อนหน้าเริ่มเมื่อโหลดไฟล์สำเร็จ และยังให้ลองใหม่ได้หลังไฟล์เสีย

## ตัวช่วยทดสอบและแพ็กเกม

- ตัวรันทดสอบและ syntax check ตรวจ `spawnSync.error` ด้วย ป้องกันผลผ่านปลอมเมื่อระบบปฏิเสธโปรเซสย่อย แม้ `status` เป็น 0 และใช้วันที่รันจริง
- เพิ่ม favicon แบบ inline เพื่อไม่ให้ HTTP browser test เกิด 404 จากการร้องขอ favicon อัตโนมัติ และปรับตัวตรวจแพ็กให้ยอมรับ `data:` asset ที่ฝังใน HTML
- สร้าง `JianghuSect_single.html` ใหม่จาก source ที่แก้แล้ว
