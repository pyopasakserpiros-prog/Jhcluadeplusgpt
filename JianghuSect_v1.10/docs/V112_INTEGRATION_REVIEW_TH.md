ZIP ไม่มีเทสต์ที่ตัวรันอ้างถึง 5 ไฟล์: กู้ 3 ไฟล์ Phase 1–3 จาก Git commit `b351692` และสร้างเทสต์ใหม่ `technique_overhaul_suites.js` กับ `patch_v1_12_suites.js`. สองไฟล์ใหม่เป็นเทสต์ตรวจเฉพาะทะเบียน ID, จำนวนพาสซีฟ, ตาราง Tier, RNG/เซฟ และตัวอย่างการได้ Tier 7 จาก Rank 1 ไม่ใช่ต้นฉบับที่ Gemini อ้างถึงและไม่ได้ทดสอบทุกกรณีของวิชา

ปรับเทสต์ browser_mobile_perf ให้ตรวจปุ่มนำทาง 6 ปุ่มพร้อมเงื่อนไขขนาดและขอบหน้าจอเดิม; เทสต์ demon_heartsoul_paths แยก passive ออกจากท่าโจมตี และตรวจว่า passive มีข้อมูล effect. สร้าง single HTML ใหม่จาก runtime
