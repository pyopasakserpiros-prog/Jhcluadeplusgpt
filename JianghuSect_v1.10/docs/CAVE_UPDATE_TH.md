# ถ้ำฉบับปรับปรุง

เริ่มเกมใหม่สำหรับฉบับนี้ แต่ละชั้นมี3พื้นที่ย่อย พื้นที่ละ3เหตุการณ์ รวม30พื้นที่และ90เหตุการณ์ เมื่อเข้าสำรวจแต่ละชั้น สุ่มเลือก1–2พื้นที่ไม่ซ้ำ แล้วสุ่มหนึ่งเหตุการณ์ตามน้ำหนักจากแต่ละพื้นที่ รางวัลจะสุ่มผ่านชุดของพื้นที่นั้นอีกครั้ง ไม่ได้รับทุกชิ้นในชุด

- ชั้น 1: โถงหมอกน้ำค้าง — โพรงค้างคาวริมปากถ้ำ / ค่ายนักสำรวจที่ถูกลืม / ลานหินรับหยาดปราณ
- ชั้น 2: เหมืองผลึกเสียงก้อง — รังสัตว์ในปล่องเหมือง / เหมืองขุดที่ปิดตาย / สายแร่สะท้อนปราณ
- ชั้น 3: สวนเห็ดในหมอกคราม — ดงอสูรสปอร์คราม / กระท่อมผู้เพาะเห็ด / แปลงเห็ดเรืองแสง
- ชั้น 4: ธารดำไร้ฝั่ง — วังวนอสูรธารดำ / ซากเรือในโพรงน้ำ / ตลิ่งเร้นใต้เงาผา
- ชั้น 5: ด่านสะพานผู้พิทักษ์ — เชิงสะพานยามศิลา / ห้องยามข้างตราผนึก / ธารปราณรอบฐานเสา
- ชั้น 6: ทะเลสาบบัวสะท้อนจิต — เกาะเงาเสียงเรียก / ศาลาเซียนจมน้ำ / ดงบัวใต้แสงปราณ
- ชั้น 7: คลังศาสตราหุ่นศิลา — ลานซ้อมหุ่นทหาร / ห้องอาวุธหลังประตูหิน / โรงช่างร้างใต้คลัง
- ชั้น 8: เตาหลอมไฟใต้พิภพ — ปล่องอสูรถ่านแดง / ห้องหลอมเก้าตรา / สายแร่ในอุโมงค์ระบายไฟ
- ชั้น 9: หอจารึกกระดูกหยก — สุสานผู้เฝ้าจารึก / หอคัมภีร์หลังผนังกระดูก / สวนผลึกหยกกลางสุสาน
- ชั้น 10: บัลลังก์ผนึกบรรพกาล — ลานราชองครักษ์ใต้พิภพ / ห้องพระราชทรัพย์หลังผนึก / ตาน้ำปราณปฐมกาล

ผู้พิทักษ์ชั้น5และ10ยังเป็นด่านสำคัญ บันทึกการสำรวจแสดงเฉพาะเหตุการณ์ที่พบจริง หน้าค้นพบซ่อนชื่อชั้นที่ยังไม่เคยไปถึง
