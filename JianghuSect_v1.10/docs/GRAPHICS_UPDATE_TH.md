# อัปเดตภาพและเอฟเฟกต์

แนวทางที่ผู้เล่นเลือก: ภาพสีสด อบอุ่นแบบสำนักยุทธภพ ใช้แผนที่และการเล่นเดิมเป็นพื้นฐาน ปรับสี พื้นผิว หลังคา ต้นไม้ และตัวละครด้วย Canvas พร้อมหน้าจอธีมหยก/ทอง

ใช้เอฟเฟกต์ร่วมกันสองชุดเพื่อประหยัดงานและทรัพยากร:
- วิชาเรียกใช้ทั่วไป: รอยพลัง/ประกายหยกและทอง
- วิชาต้องห้ามที่เรียกใช้: วงอักขระม่วงแดง

ไม่แยกเอฟเฟกต์รายวิชา เอฟเฟกต์เกิดหลังระบบต่อสู้เลือกใช้วิชาและหักต้นทุนจริง ใช้ได้กับ NPC และศัตรู การตีธรรมดา สถานะติดตัว คูลดาวน์ และการใช้วิชาที่ถูกผนึกไม่ทำให้เกิดเอฟเฟกต์ใหม่

ข้อมูลแจ้งการใช้วิชาแยกจากข้อความความเสียหายเพื่อไม่ให้ข้อความโดนโจมตีทับภาพของผู้ร่าย ตัวแสดงภาพจัดการอายุและจำนวนเอฟเฟกต์เองและไม่เรียก RNG ของเกม

ตรวจด้วยชุด regression รวม, Chromium จอมือถือ/เดสก์ท็อป และภาพจากเกมจริง รายละเอียดภาพและประสิทธิภาพอาจต่างกันตามอุปกรณ์
