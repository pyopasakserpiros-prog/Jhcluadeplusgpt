## สิ่งที่เพิ่มจากเกมหลักเดิม

- NPC: ความฝัน 9 แนว เป้าหมายหลายระยะ การประเมินวิชา/อุปกรณ์ ความสัมพันธ์หลายมิติ การให้ของ/ช่วยเหลือ คำมั่น การสอน การรักษาหน้าที่และอำนาจรักษาการ การประจบ/ความเกรงใจ และพฤติกรรมผลประโยชน์ส่วนตน พร้อม UI อธิบาย
- กราฟิก: ขยาย renderer และธีม UI ท่าทาง/อุปกรณ์/ภาพตัวละคร อาคารและสภาพแวดล้อม คุณภาพภาพและการลดการเคลื่อนไหว โดยยังใช้ Canvas และ DOM เดิม
- เพิ่ม `js/visitors_clues.js`: ผู้มาเยือนที่ไม่เป็นสมาชิก การยอมรับ/จำกัดสิทธิ ความทรงจำการมาเยือน ข่าว/ผู้รู้ การสืบเบาะแส และการเชื่อมคณะเดินทาง
- ข้อมูลในโมดูลใหม่: 41 เส้นเบาะแส (ทั่วไป 8, วิชาในตำนาน 22, อาวุธในตำนาน 11) และอาวุธ 11 ชิ้นครบ 7 ประเภท ข้อมูลวิชาและไอเทมเดิมในโฟลเดอร์ data ไม่ถูกแก้โดย ZIP นี้ แต่โมดูลใหม่เพิ่มข้อมูลขณะโหลด
- คง Phase 1–3 และแพทวิชาเดิมไว้ ส่วนระบบใหม่เพิ่มโค้ดจำนวนมาก การทดสอบผ่านไม่ได้รับรองว่าทุกเส้นทางสมเหตุสมผลทั้งหมด

## บัคที่ทำซ้ำและแก้แล้ว

สร้าง `test/codex_combined_review.js` ก่อนแก้ และยืนยันว่าแต่ละกรณีล้มกับโค้ดก่อนแก้:

1. **รับรางวัลก่อนผ่านเรื่องราว:** `grantNamedStoryReward` ตรวจใบเสร็จซ้ำ แต่ไม่ตรวจ completedNodes จึงรับอาวุธได้ทันทีจากเบาะแสใหม่ เพิ่มการตรวจสถานะและขั้นที่ผ่านครบก่อนจ่าย เปลี่ยน fixture ทดสอบใบเสร็จเดิมให้ตั้ง prerequisites ชัดเจน แยกจากการทดสอบห้ามข้ามขั้น
2. **โหลดเซฟแล้วคูลดาวน์อาวุธหาย:** เก็บใน `_wpnProcCds` แต่ serializer ตัดฟิลด์ขึ้นต้น underscore จึงใช้เอฟเฟกต์ซ้ำได้ทันทีหลังโหลด เปลี่ยนเป็น `wpnProcCds` ที่บันทึกได้ รวมจุดตรวจมีดบินก่อนโจมตีด้วย เซฟเก่าที่ไม่เคยบันทึกคูลดาวน์ไม่สามารถกู้เวลาที่หายย้อนหลังได้
3. **เบาะแสหมดอายุยังรับรางวัลได้:** evaluateClueNode กันเฉพาะ claimed/disproven เพิ่มการกันทุกสถานะ terminal และตรวจวันหมดอายุทั้ง active/in_progress
4. **วางแผนแล้วทำกิจกรรมทันที:** VC.daily และ departClueExpedition เรียกประเมินขั้นในสำนักโดยไม่ผ่านกิจกรรมจริง เปลี่ยนให้ AI.ACTS.investigateClueLocal ดำเนินงานจนจบก่อน ไม่แจกความคืบหน้าจากคำสั่งวางแผน
5. **ประวัติที่จบแล้วปิดระบบข่าวใหม่:** cap และ activeTemplateIds นับ terminal records ด้วย จึงหมดโควตาเมื่อสะสมครบ 32 และเบาะแสทั่วไปไม่กลับมาตาม cooldown แก้ให้นับเฉพาะงานค้าง เก็บรายละเอียด terminal ล่าสุดแบบมีขอบเขต รักษาใบเสร็จถาวรและรายการที่คณะเดินทางยังใช้อยู่ ล้างรายการอ้างอิงที่หมดอายุจากสมาชิก/คลังเบาะแส
6. **ดึงคนออกจากกิจกรรมที่ต้องคุ้มครอง:** ภารกิจใหม่ข้าม AI.isProtectedAction ที่ระบบคณะเดินทางปกติใช้ เพิ่มการตรวจผู้นำ ผู้ร่วมเดินทาง และ customParty รวมคนตาย/ออกสำนัก/ติดคุก/ผนึก/กำลังเดินทาง และห้ามสมาชิกซ้ำ

เพิ่มการป้องกันล่วงหน้า: ประเมินขั้นภายนอกเฉพาะเมื่อ locationId ตรงภูมิภาคที่คณะเดินทางถึงจริง โค้ดเดิมอาจประเมินสองขั้นต่อกันโดยไม่ตรวจปลายทาง แต่ข้อมูล 41 เส้นปัจจุบันยังไม่พบคู่ขั้นภายนอกติดกันที่ต่างภูมิภาค จึงไม่รายงานว่าได้ทำซ้ำบัคนี้ในเนื้อหาปัจจุบัน

## หลักฐานและขอบเขตการตรวจ

- ZIP เดิมผ่าน aggregate suite 61/61 กลุ่ม รวม syntax แต่ยังพบช่องโหว่ข้างต้น แสดงข้อจำกัดของ coverage เดิม

- ชุดทดสอบ 41 เส้นของ Gemini ใช้ forcePass จึงพิสูจน์การเดินข้อมูลและการจ่าย ไม่ได้พิสูจน์ความเป็นไปได้/ความยากตามธรรมชาติของทุกบททดสอบ การทดสอบภาพอาวุธบางส่วนใช้ mock canvas ไม่ใช่การตรวจภาพจริงครบทุกชิ้น

- workload ควบคุม 100 NPC + 6 guests, 1440 ticks และ save/load ผ่าน เป็นการตรวจสั้น ไม่ใช่การจำลองเศรษฐกิจระยะยาวที่ประชากร 100 คน ดู `CODEX_COMBINED_VERIFICATION.json`
