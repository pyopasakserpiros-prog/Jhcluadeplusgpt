# รากฐานตัวตน NPC — แพตช์ 1.1

เป้าหมายคือให้คนที่อยู่ในสถานการณ์เดียวกันมีเหตุผล ความต้องการ และความสามารถต่างกันอย่างตรวจสอบได้ ระบบนี้เป็นแบบจำลองสำหรับเกมสำนัก ไม่ใช่ข้ออ้างว่าตัวเลขชุดหนึ่งอธิบายมนุษย์จริงได้หมดหรือจะไม่มีเหตุให้แก้ข้อผิดพลาดในอนาคต

## ตัวตนมีสามชั้น

| ชั้น | ประกอบด้วย | เปลี่ยนเมื่อใด |
|---|---|---|
| รากฐานของคน | คุณค่าชีวิต 8, บุคลิก 14, กายภาพ 14, การคิด 12, พรสวรรค์ 6, ความสนใจ 14, สรีระและรูปลักษณ์ | สร้างครั้งเดียวและบันทึกไว้ กิจกรรมใหม่ใช้ค่าชุดนี้ |
| สภาพที่กำลังเผชิญ | สุขภาพ ความหิว ความล้า ความเครียด ความเจ็บ ความบกพร่อง 6 ส่วน ความโศกเศร้า ความต้องการอิสระ ความสามารถ และความแปลกใหม่ | ตามเวลา งาน การปะทะ การพัก และเหตุการณ์ |
| ชีวิตที่สะสม | ความรู้เดิม วิชา สูตร สิ่งของ ความชำนาญ ความทรงจำ บทเรียน ความสัมพันธ์ และความปรารถนา | เฉพาะเมื่อมีการเรียนรู้ การกระทำ หรือเหตุการณ์ที่เกี่ยวข้อง |

ทุกชั้นอยู่ใน `world.npcs[npc.id]` คนเดียวกัน รายชื่อเก็บเพียง ID ไม่มีตัวละครฉบับ UI หรือฉบับ AI ที่สุ่มคนละชุด

`HUMAN_FIELD_REFERENCE.md` แจกแจงครบทั้ง 68 แกนและตำแหน่งหลัก ส่วน `HUMAN_REGISTRY.json` มีนิยามข้อมูลของกิจกรรมและวิถีทั้งหมด เพื่อให้ระบบใหม่อ่านและตรวจสอบได้

## ความหมายของตัวเลข

ค่าพื้นฐานใช้ 0–100 โดย 50 เป็นจุดอ้างอิงของเกม ค่านิยมบอกระดับความสำคัญ ไม่ต้องรวมกันเป็น 100 บุคลิกเป็นแนวโน้ม ไม่มีข้อกำหนดว่าทุกแกนสูงแล้วเป็นคนดีกว่า ส่วนการใช้พลังงานสูงทำให้หิวเร็วขึ้น ความชอบสูงเพิ่มแรงอยากทำ แต่ไม่ได้มอบทักษะที่ยังไม่เคยฝึก

ความสามารถด้านการคิดใช้หลายองค์ประกอบ: ให้เหตุผล วางแผน ความจำใช้งาน สมาธิ ความจำเหตุการณ์ ความเร็วประมวลผล ความเข้าใจปริมาณ พื้นที่ ภาษา ระบบ ผู้อื่น และข้อจำกัดตนเอง การคิดดีไม่เปลี่ยนค่านิยมหรือศีลธรรมของคนโดยอัตโนมัติ

ความสูง น้ำหนัก มือถนัด สีผิว สีผม และสีตาเป็นลักษณะบรรยายและภาพแสดงตัว ไม่ใช้กำหนดสติปัญญาหรือคุณธรรม รูปร่างและสีปรากฏในภาพตัวละคร ขนาดภาพไม่ใช่โบนัสการต่อสู้

## ความสามารถพื้นฐานกับความพร้อมขณะนี้

ใช้ค่าพื้นฐานร่วมกับความล้า ความหิว ความเครียด สุขภาพ ความเจ็บ และส่วนที่บาดเจ็บ ค่าที่ได้รับผลจะลดลงชั่วคราว การพักและรักษาคืนสภาพได้โดยไม่สุ่มพื้นฐานใหม่

| กลไก | ค่าที่มีผลจริง |
|---|---|
| ระยะเดินต่อวินาที | ความคล่องตัว การทรงตัว ช่วงเคลื่อนไหว การประสานร่างกาย สภาพปัจจุบัน และภาระเกินกำลัง |
| เก็บของและบรรทุก | แรงกล้ามเนื้อ ความอึด ความถนัดมือ การรับรู้ และทักษะเก็บทรัพยากร โดยหักจากแหล่งที่มีอยู่จริง |
| ความเร็วงาน | สัดส่วนกายภาพ การคิด พรสวรรค์ และทักษะของกิจกรรมนั้น |
| ความก้าวหน้าบ่มเพาะ | การเรียนรู้จากความสามารถคิดและพรสวรรค์ แล้วส่งเข้าระบบบ่มเพาะต้นฉบับ |
| ปะทะ | กำลังรบต้นฉบับ คูณความพร้อมของร่างกายและการคิดเชิงพื้นที่ ความทนต่อแรงกระแทกลดความเสียหาย |
| ฟื้นตัว | อัตราฟื้นตัวและความทนทานทางชีวภาพ ลดความเจ็บและความบกพร่องพร้อมกับสุขภาพที่ดีขึ้น |
| หิวและเหนื่อย | อัตราใช้พลังงาน ความอึด และประเภทสภาพงาน |
| งานช่างจริง | ช่างที่รับงานเป็นผู้ให้ค่าความสามารถ ระยะงานโอสถและศาสตราเปลี่ยนตามความพร้อม โอสถปรับโอกาสสำเร็จด้วย โดยยังใช้วัตถุดิบและผลสุ่มเดิม |
| ผูกมิตร | ความเข้าใจผู้อื่นและการสื่อสารกำหนดผลของการพบกันจริง |

วัตถุที่ถือเกินกำลังเดิมไม่ถูกลบ แต่ทำให้เดินช้าลง ศิษย์ไม่เลือกเก็บแร่หรือสมุนไพรต่อเมื่อไม่มีที่บรรทุกหรือแหล่งหมด

## การตัดสินใจ

คะแนนของตัวเลือกประกอบด้วยสถานการณ์ ระยะทาง นโยบาย ความต้องการ ความปรารถนา ความทรงจำ และตัวปรับของเครื่องยนต์เดิม ได้แก่ บุคลิก ค่านิยม พรสวรรค์ ความเสี่ยง คุณลักษณะเฉพาะ และต้นทุน จากนั้นใช้ส่วนเพิ่มเติมดังนี้

- ความชอบกิจกรรม: ประกอบจากแรงสนใจทั่วไป เช่น วิเคราะห์ สร้างสรรค์ ดูแล แข่งขัน และสงบ
- การประเมินความสามารถตน: ความพร้อมของงานนั้นร่วมกับความรู้ข้อจำกัดตน
- แรงขับที่ยังขาด: ความต้องการกำหนดชีวิต ความรู้สึกพัฒนา และสิ่งใหม่
- การประเมินอันตราย: เปรียบเทียบความเสี่ยงกับกำลัง ความพร้อม และสุขภาพ

ใช้ `scoreNpcDecisionOptions` และ `chooseNpcDecisionOption` ของต้นฉบับ ตัวเลือกทุกกิจกรรมจริงมีน้ำหนักค่านิยม ความชัดเจนในการคิดกำหนดระดับความผันแปรของการเลือก ไม่ได้ทำให้ทุกคนเลือกคะแนนสูงสุดเหมือนกัน

ค่านิยมที่ขัดกันสามารถออกแรงคนละทิศ เช่น ความสำคัญต่อส่วนรวมเพิ่มคะแนนส่งของเข้าคลัง ขณะที่ความสำคัญต่อทรัพย์ส่วนตัวอาจลดคะแนนการบริจาคของตน การให้คุณค่ากับครอบครัวปัจจุบันส่งผลต่อการดูแลตนและสังคม ยังไม่มีการแต่งงานหรือการเลี้ยงบุตรในหุบเขารุ่นนี้

27 วิถีย่อยมีรายละเอียดความต้องการของตนเอง เช่น โอสถใช้ความละเอียดมือ ปริมาณ สมาธิ และการเข้าใจระบบ ส่วนกระบี่ใช้การควบคุมมือ ความคล่องตัว การคิดเชิงพื้นที่ และแรงสนใจแข่งขัน ลำดับในอาร์เรย์ไม่มีความหมายในการเลือกสายแล้ว

หน้า “ความคิด” แสดงคะแนนจริงครั้งล่าสุด พร้อมแยกค่านิยม บุคลิก พรสวรรค์ ความชอบ แรงขับ การประเมินความสามารถ และความเสี่ยง

## ความชอบ พรสวรรค์ ความรู้ และความชำนาญ

ทั้งสี่อย่างเป็นคนละข้อมูล คนชอบหลอมยาอาจไม่มีพรสวรรค์และยังไม่เคยทำงานนั้น คนมีพรสวรรค์อาจไม่อยากทำ ทักษะเพิ่มจากการฝึกและส่งผลต่อความพร้อม แต่ไม่เขียนทับความชอบหรือค่านิยม

สูตร วิชา สิ่งของ และการบ่มเพาะยังใช้บัญชีต้นฉบับ ในเกมปัจจุบันศิษย์ที่ไปว่าจ้างช่างสะสมการเจรจา ช่างที่ผลิตสำเร็จสะสมทักษะโอสถหรือศาสตรา ไม่บันทึกว่าผู้ว่าจ้างเป็นผู้หลอมเอง

## ความทรงจำและบทเรียน

เก็บเหตุการณ์ที่พบจริงสูงสุด 32 รายการ มีเวลา กิจกรรม ผลทางบวกหรือลบ ข้อความ และแหล่งที่มา เหตุการณ์ซ้ำชนิดเดียวกันภายใน 30 วินาทีจะไม่ถูกนับซ้ำในทิศทางเดียวกัน ประสบการณ์สำเร็จและบาดเจ็บใกล้กันยังแยกกันได้

ดึงความทรงจำตามกิจกรรมที่เกี่ยวข้องและระยะเวลาที่ผ่านไป ความจำเหตุการณ์กำหนดระยะคงอยู่ มีสถิติสะสมต่อกิจกรรม และทุก 4 ประสบการณ์สรุปเป็นบทเรียนที่มีจำนวนเหตุการณ์รองรับ บทเรียนส่งผลต่อการเลือกได้นานกว่ารายละเอียดตอนเดียว แต่ยังค่อย ๆ จางลง เก็บบทเรียนล่าสุด 12 รายการ

ระบบเป็นการคำนวณภายในเครื่อง ไม่เรียก LLM และไม่แต่งเหตุการณ์ย้อนหลัง อารมณ์เป็นค่าที่อนุมานจากสภาพชีวิต ส่วนความโศกเศร้าต่อการตายของสหายคงอยู่เป็นสภาพชั่วคราวและมีผลต่อความเครียด

## สัญญาสำหรับระบบในอนาคต

เพิ่มกิจกรรมด้วย `HumanCore.registerActivity` โดยกำหนด ID ชื่อ น้ำหนักของค่านิยม บุคลิก กายภาพ การคิด พรสวรรค์ ความสนใจ ความต้องการที่ตอบสนอง และชื่อทักษะที่ฝึกได้ ไม่เพิ่มแกน “ชอบวิถีใหม่ X” เข้าในตัวตน NPC ทุกคน

ดูตัวอย่างที่รันได้ใน `examples/new-discipline.js` การทดสอบยืนยันว่ากิจกรรมใหม่คำนวณความชอบและความสามารถได้โดยข้อมูลพื้นฐานและลายเซ็นไม่เปลี่ยน เมื่อฝึกเพิ่มเฉพาะรายการทักษะที่เรียนได้ การลงทะเบียนที่อ้างแกนซึ่งไม่มีอยู่จะถูกปฏิเสธ

`npc.id` คือกุญแจประจำตัวหลัก `identityId` และลายเซ็นค่าพื้นฐานใช้ช่วยอ่านและเปรียบเทียบ ไม่ใช้แทน ID หลักหรือใช้ตรวจความถูกต้องของไฟล์เซฟ

`core.human.schemaVersion = 1` เป็นสัญญาข้อมูลที่ควรรักษา ระบบใหม่ขยายรายการความรู้ ทักษะ กิจกรรม เหตุการณ์ หรือบริบทสังคมได้ หากต้องเปลี่ยนสัญญาจริงต้องมี migration ชัดเจน ไม่เติมแกนแบบเงียบ ๆ และไม่อ้างว่าจะไม่มีการแก้บั๊กในอนาคต

## การรับเซฟเดิม

บันทึกโลกยังอ่านรุ่น 1 ได้ การเติม Human Foundation ใช้เมล็ดโลกกับ NPC ID และชื่อแต่ละแกนอย่างเป็นอิสระ ไม่ใช้ผลสุ่มของโลก ไม่เปลี่ยนค่านิยม บุคลิก ความฉลาดเดิม วิถี สุขภาพ สัมภาระ หรือจุดที่ยืนอยู่ NPC ใหม่เท่านั้นที่ได้รับการให้เหตุผลและการวางแผนเฉพาะคน แทนค่าที่ตัวสร้างต้นฉบับคัดลอกจากแม่แบบ

ทดสอบด้วยเซฟที่สร้างจากโค้ด v1.0 จริง รวมกรณีค่านิยมเป็น 0 การเติมซ้ำให้ผลเดิม เซฟที่มีรากฐานรุ่นใหม่กว่าเกมหรือฟิลด์หลักเสียหายจะรายงานข้อผิดพลาดแทนการล้างตัวตน

## ที่มาของแนวคิด

ใช้หลักเรื่องความต่างระหว่างค่านิยมกับนิสัยจาก [Schwartz (2012)](https://scholarworks.gvsu.edu/orpc/vol2/iss1/11/) เป็นแนวทางแยกหน้าที่ แต่คง 8 ค่านิยมของโลก Jianghu ไม่ได้นำแบบวัด 10 ค่านิยมมาอ้างเป็นระบบเดียวกัน

ใช้แนวคิดความต้องการอิสระ ความสามารถ และความสัมพันธ์จาก [Self-Determination Theory](https://selfdeterminationtheory.org/theory/) เพื่อออกแบบแรงขับชั่วคราว ตัวเลขและน้ำหนักทั้งหมดเป็นการออกแบบเกม

ใช้แนวคิดแยกความทรงจำ การดึงข้อมูล และการสะท้อนประสบการณ์จาก [Park และคณะ (2023), Generative Agents](https://arxiv.org/abs/2304.03442) เป็นแรงบันดาลใจ รุ่นนี้ใช้เหตุการณ์เชิงโครงสร้างและการสรุปตามกฎ จึงทำงานออฟไลน์และไม่มีคำอ้างว่าใช้สถาปัตยกรรม LLM ของงานวิจัยนั้น
