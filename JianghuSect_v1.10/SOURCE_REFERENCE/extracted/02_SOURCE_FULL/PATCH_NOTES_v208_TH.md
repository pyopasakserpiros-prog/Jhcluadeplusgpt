# แพตช์ 2.08 — ตรวจและแก้ความสมเหตุสมผลของเศรษฐกิจสำนัก

ต่อยอดจาก 2.07 โดยแก้สาเหตุจริงที่ทำซ้ำได้ในเอนจิ้น ไม่เปลี่ยนรากฐานตัวตน NPC

| จุดที่พบ | พฤติกรรมหลังแก้ |
|---|---|
| ขาดวัตถุดิบส่วนตัว 1 หน่วย แต่เส้นทางเบิกวัตถุดิบซื้อให้ 2 หน่วย | ส่งจำนวนที่ขาดจริงไปจนถึงคำร้องและการหักแต้ม เช่น ขาดหญ้าน้ำค้าง 1 หน่วย ใช้ 7 แต้ม ไม่ใช่ 14 และผู้ที่มี 7 แต้มซื้อได้ |
| NPC เรียนรู้สูตรจากภายนอกแล้ว แต่รายการหลอมให้สำนักยังมองเฉพาะสูตรชุดเก่า | รวมสูตรที่สมาชิกเรียนรู้จริงเป็นตัวเลือกงานและแสดงในโรงช่าง โดยยังตรวจฝีมือ ขอบเขต วัตถุดิบ และความต้องการก่อนทำ |
| อุปกรณ์ที่หลอมให้สำนักทำคุณสมบัติบางอย่างจากสูตรหาย | คงฤทธิ์เฉพาะจากสูตร เช่น โบนัสจารึกยันต์และความปลอดภัยคุ้มกัน พร้อมระบุผู้สร้าง/เจ้าของจริงตามเดิม |
| ระบบอัตโนมัติอัปเกรดอาคารรอง แม้อีกหลังในประเภทเดียวกันสูงกว่าและโบนัสไม่เพิ่ม | พิจารณาผลที่เพิ่มจากระดับสูงสุดจริงก่อนเสนออัปเกรด ผู้เล่นยังสั่งเพิ่มความทนทานของอาคารแต่ละหลังได้ |
| ขาดแต้มอย่างเดียวก็อัปเกรดหอภารกิจ แม้ช่องงานเดิมว่าง | ต้องมีทั้งผู้ขาดแต้มและช่องจัดหาหรือผลิตที่ใช้งานเต็ม จึงพิจารณาจ่ายทรัพยากรเพิ่มช่องงาน |
| นับกิจกรรมเก่าของคนที่ไม่ได้ทำงานอยู่เป็นการใช้ช่องงาน | ใช้จำนวนคนมีชีวิตที่กำลังทำงานหรือเดินไปทำงานในฉากจริง และใช้ตัวนับเดียวกันทั้งการเสนองานและมติอัปเกรด |
| ยาแก้พิษธรรมดาถูกปฏิเสธจากสวัสดิการเพราะอ่านชื่อฤทธิ์ผิด | ใช้ฤทธิ์ clearPoison ที่ระบบโอสถใช้จริง ทำให้ยาแก้พิษพื้นฐานเข้าเกณฑ์เช่นเดียวกับยารักษา |
| ยาที่มีฤทธิ์ฟื้นฟูร่วมกับโบนัสความก้าวหน้าอาจถูกแจกเป็นของใช้พื้นฐาน | ตรวจทุกฤทธิ์เพิ่มตบะ รากฐาน ความเข้าใจมรรคา อายุขัย ต้านทัณฑ์ และเปิดชีพจร แยกจากยาฟื้นฟูพื้นฐาน |
| การค้าคนนอกมีเพียงฝั่งซื้อเข้า ยังไม่มีใบสั่งซื้อรับซื้อของส่วนเกิน (Purchase Orders) | เพิ่มขบวนคาราวานเฉพาะทาง 5 สาย (`CARAVAN_GUILDS`), ระบบใบสั่งซื้อรับซื้อของส่วนเกินจากสำนักพร้อมโบนัสเฉพาะโควตาแรก (`bonusQuota`), การกันสำรองคลัง/โรงหลอม/งานก่อสร้าง/ของที่ศิษย์เล็งซื้อ (`orderReserve`), การประเมินขายส่วนเกินอัตโนมัติของเจ้าสำนัก/ผู้อาวุโส (`autoSellSurplus`), ปุ่มควบคุมใน UI และการป้องกันปั่นกำไรหินวิญญาณ |
