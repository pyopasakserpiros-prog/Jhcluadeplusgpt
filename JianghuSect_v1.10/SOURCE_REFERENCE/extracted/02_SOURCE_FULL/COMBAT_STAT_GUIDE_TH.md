# คู่มือคอมแบทและสเตตัส 2.01

เปิดข้อมูลศิษย์ → **สเตตัสต่อสู้** หรือเปิดชุดวิชาแล้วกดดูคุณสมบัติ อสูรป่าเปิดจากหน้าภูมินิเวศ และคู่หูเปิดจากหน้าคู่หูอสูร ทุกหน้ามีค่าพื้นฐาน ค่าปัจจุบัน และรายละเอียดที่มาของแต่ละค่า

## ค่าที่ใช้จริง

| ค่า | ที่มาหลัก | ผลในการเล่น |
|---|---|---|
| พลังชีวิตสูงสุด | ความอึด ความทนทาน แรงกาย ตบะ อุปกรณ์ | รับความเสียหายได้มากขึ้นก่อนตาย |
| พลังโจมตีกาย | กล้ามเนื้อ พลังระเบิด การประสานร่างกาย พรสวรรค์ต่อสู้ ศาสตรา วิชากาย | หมัดพื้นฐานและวิชากายแรงขึ้น |
| พลังโจมตีวิชา | สมาธิ การให้เหตุผล ความเข้าใจ เส้นปราณ พรสวรรค์บ่มเพาะ คัมภีร์ที่เตรียม | วิชาปราณและจิตวิญญาณแรงขึ้น |
| เกราะกาย | ความทนทาน ความอึด การทรงตัว เกราะและวิชาคุ้มกาย | ลดความเสียหายกาย |
| ต้านทานวิชา | ภูมิต้านทาน เส้นปราณ สมาธิ ความเข้าใจ อุปกรณ์ | ลดความเสียหายวิชาและบางส่วนของความเสียหายต่อเนื่อง |
| แม่นยำ | การประสานร่างกาย ประสาทสัมผัส การกะพื้นที่ พรสวรรค์ต่อสู้ | ลดโอกาสโจมตีพลาด |
| หลบหลีก | ความคล่อง การทรงตัว การกะพื้นที่ วิชาตัวเบา | เพิ่มโอกาสหลบการโจมตีตรง |
| โอกาสคริ | ความละเอียดมือ ประสาทสัมผัส พรสวรรค์ต่อสู้ | ปะทะจุดสำคัญ; มีคำว่า **คริ!** สีทองในฉาก |
| ความแรงคริ | พลังระเบิด การกะพื้นที่ อุปกรณ์ที่เสริมโดยตรง | ตัวคูณความเสียหายเมื่อคริ |
| ความเร็วออกท่า | ความคล่อง การประสานร่างกาย ความเร็วประมวลผล วิชาตัวเบา | จำนวนครั้งต่อวินาที; ไม่ลบคูลดาวน์เฉพาะวิชา |
| ความเร็วเคลื่อนที่ | ความคล่อง ช่วงการเคลื่อนไหว ความอึด วิชาตัวเบา | ความเร็วเคลื่อนเข้าระยะ ไล่ตาม หรือเดินทาง; โหมดเดินลาดตระเวนมีจังหวะช้าลง |
| เจาะเกราะ | พลังระเบิด ความละเอียดมือ เส้นปราณ วิชาและอุปกรณ์ | หักเกราะกายหรือต้านวิชาก่อนลดดาเมจ |
| ต้านการควบคุม | ความอึด การรู้ข้อจำกัดตน ความสมบูรณ์เส้นปราณ | ลดเวลาเสียจังหวะ; ยังมีเวลาคุ้มกันไม่ให้ถูกคุมติดกันตลอด |
| ปราณสูงสุด | ความจุเส้นปราณ พรสวรรค์บ่มเพาะ ตบะ วิชาเดินปราณ | ใช้วิชาได้นานขึ้น |
| ฟื้นปราณ | การฟื้นตัว เส้นปราณ สมาธิ พรสวรรค์บ่มเพาะ วิชาสนับสนุน | ฟื้นต่อวินาที; ระหว่างต่อสู้ฟื้น 30% ของอัตราปกติ |

ค่านิสัยและค่านิยมใช้เลือกท่า ประเมินความเสี่ยง วางแผนและตัดสินใจถอย ไม่บวกพลังโจมตีหรือคริให้โดยตรง คนที่ใช้ร่างกายและอุปกรณ์เหมือนกันใช้กติกาเดียวกันทั้งสองฝ่าย

## สูตรหลัก

- การโจมตีพื้นฐานใช้พลังโจมตีกาย วิชาของวิถีกายใช้กาย วิถีอื่นใช้พลังวิชา เว้นแต่วิชากำหนดชนิดไว้โดยตรง
- ดาเมจตั้งต้น = พลังโจมตีของชนิดนั้น × 0.55; วิชาเพิ่มตัวคูณตามอานุภาพ ความชำนาญ บทบาท และการต่อเคล็ด
- เกราะที่เหลือ = ค่าสูงสุดระหว่าง 0 กับ (เกราะของชนิดดาเมจ − เจาะเกราะ)
- ดาเมจหลังเกราะ = ดาเมจตั้งต้น × 100 ÷ (100 + เกราะที่เหลือ)
- โอกาสโดน = 90% + (แม่นยำ − หลบหลีกเป้าหมาย − 75) × 0.25%; จำกัด 55–98% วิชาหลบที่กำลังทำงานลดโอกาสโดนเพิ่มอีก 13 จุดร้อยละ
- ถ้าโจมตีโดนจึงทอยคริหนึ่งครั้ง และคูณด้วยความแรงคริ จากนั้นจึงใช้ผลปัดป้อง คุ้มครอง และค่ายกลที่กำลังทำงาน
- จังหวะออกท่า = 1 ÷ ความเร็วออกท่า เช่น 0.8 ครั้ง/วินาที ใช้เวลาประมาณ 1.25 วินาทีต่อครั้ง
- ดาเมจต่อเนื่อง สะท้อน และแบ่งรับแทนไม่ทอยคริหรือหลบซ้ำ

ค่าสัมประสิทธิ์อานุภาพอุปกรณ์เดิมถูกแปลงเป็นส่วนเพิ่มของค่าสู้ใหม่: โจมตีเพิ่ม `(100 + โจมตีพื้นฐาน) × combatMult` และเกราะ/ต้านวิชาเพิ่ม `(60 + ค่าพื้นฐาน) × defenseMult` จึงเห็นผลของศาสตราขั้นต้นได้ชัด และสูตรที่มีสัมประสิทธิ์สูงกว่ายังอัปเกรดต่อได้ โบนัสศาสตราจิตและชุดนับแยกตามของที่ใช้ได้จริง

อุปกรณ์ต้องอยู่ในกระเป๋าจริง สวมในช่องตรงชนิด ผ่านขั้น/สายที่กำหนด และยังมีความทนทาน วิชาในหน้าความรู้แต่ยังไม่ได้เตรียมจะไม่เพิ่มค่าสู้ โบนัสอักขระที่ฝังในอุปกรณ์แล้วจะไม่นับซ้ำ จิตศาสตราและโบนัสชุดนับจากอุปกรณ์ที่ใช้ได้จริงเท่านั้น

## สุขภาพกับ HP

NPC ยังใช้สุขภาพก้อนเดิมของระบบชีวิต เช่น 0–100 เพื่อให้บาดแผล โอสถ ความหิวและความตายสัมพันธ์กัน HP ในหน้าต่อสู้เป็นค่าที่แสดงตามสัดส่วน เช่น HP สูงสุด 200 และสุขภาพ 50/100 จะแสดง HP 100/200 เมื่อโดน 20 HP จะเสียสุขภาพ 10 หน่วย ไม่มีเลือดอีกก้อนที่รักษาหรือตายแยกกัน

อสูรใช้ health/maxHP ของตัวเองโดยตรง อสูรเร็ว เกราะหนา จิตวิญญาณ และแบบสมดุลมีจุดเด่นต่างกัน วัย ตัวตน และอวัยวะกลายพันธุ์มีผลโดยไม่สุ่มใหม่เวลาเปิดดู อสูรมีท่าพิเศษและคูลดาวน์ของตัวเอง คู่หูได้รับชื่อผู้โจมตีของตัวเอง ส่วนผลตอบแทนการสังหารส่งให้เจ้าของ

## อ่านฉากต่อสู้

- ตัวเลขดาเมจอยู่เหนือผู้ถูกโจมตี; คริเป็น **คริ!** สีทองและตัวใหญ่
- ชื่อกระบวนท่าอยู่เหนือผู้ใช้ แม้เป้าหมายจะหลบท่านั้น
- หลบ การรักษา การตั้งรับ และการต่อเคล็ดใช้ข้อความแยก
- ข้อความซ้อนจะจัดชั้นและจำกัดจำนวนต่อเฟรมเพื่อรักษาความอ่านง่าย

แดนหมื่นภพใช้ค่าสู้และสูตรคาดหมายเดียวกันในการสรุปการปะทะ มีการจ่ายค่าวิชาจริงและเก็บค่าของคู่ต่อสู้ในบันทึกการพบ แต่ยังเป็นการจำลองสรุปนอกฉาก ไม่ใช่การเปิดสนามต่อสู้ทีละเฟรมใหม่
