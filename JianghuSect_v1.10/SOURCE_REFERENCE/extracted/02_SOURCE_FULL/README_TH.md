# Jianghu 2.08.3 — Academy Formula Recovery + EP.5 Fix + Speed ×16

เปิด `Jianghu_Ascension_Myriad_Worlds_v2_08_3.html` ในเบราว์เซอร์เพื่อเล่นออฟไลน์ได้เลย โค้ด ภาพ และแบบอักษรฝังอยู่ในไฟล์ HTML เดียว

## แพตช์นี้แก้อะไร

- แก้เซฟเดิมที่ NPC บางตัวมี `stageLocal` แต่ไม่มี `stageLocal.needs` ซึ่งทำให้หน้าแฟ้มศิษย์อ่าน `hunger` แล้วเกมหยุด
- เพิ่มการซ่อมข้อมูลที่ขาดหายตอนโหลดเซฟ โดยเก็บค่าที่มีอยู่เดิมและเติมเฉพาะค่าที่ขาด (`hunger: 20`, `social: 25`, `safety: 10`)
- เพิ่ม guard ในหน้าแฟ้มศิษย์ เพื่อให้ข้อมูลเก่าหรือข้อมูลผิดรูปแบบไม่ทำให้หน้าจอหยุดทั้งเกม
- เพิ่มความเร็วจำลองเป็น ×1, ×2, ×4, ×8 และ ×16; กดปุ่มความเร็วเพื่อวนระดับ
- ปรับขีดจำกัด catch-up ของ simulation จาก 24 เป็น 48 steps ต่อเฟรม และแก้ความคลาดเคลื่อนเลขทศนิยมที่ขอบ step เพื่อรองรับความเร็วสูง
- แก้การถ่ายทอดตำรับจากเซฟเก่าที่ไม่มี `licenses` array และกู้คืนงาน `shareFormula` ที่บันทึกไปเพียงบางส่วน โดยไม่เพิ่มสูตรซ้ำ
- ไม่เปลี่ยน save envelope/schema และไม่แก้ `human.js` หรือ `legacy.bundle.js`

## วิธีอัปเดตเซฟ

1. ก่อนเปลี่ยนเวอร์ชัน ให้ส่งออกเซฟเก็บไว้หนึ่งชุด
2. เปิด HTML เวอร์ชัน 2.08.3 และโหลด/นำเข้าเซฟเดิม
3. ระบบเติมข้อมูลความต้องการที่ขาดหายโดยอัตโนมัติ ไม่ต้องเริ่มโลกใหม่เพื่อแก้บั๊กนี้
4. ทดลอง EP.5 และเริ่มที่ ×4 ก่อน แล้วค่อยเพิ่ม ×8 หรือ ×16 หากภาพและการจำลองยังลื่น

ความเร็วจริงขึ้นกับเบราว์เซอร์ จำนวน NPC และภาระงานในฉาก แม้ Snapdragon 8 Elite จะมีประสิทธิภาพสูง ก็ยังต้องตรวจ FPS และความร้อนบนเครื่องจริงก่อนรับรองว่า ×16 ลื่นทุกสถานการณ์
