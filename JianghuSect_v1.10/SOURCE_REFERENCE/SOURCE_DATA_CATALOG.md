## Inspected non-save snapshot

[inspected_catalog.json](catalogs/inspected_catalog.json) preserves the complete non-save registry extraction used for this task. It contains `generatedAt`, `provenance`, exact `loaded` module names, `source` data, baseline `target` shapes and `sourceOnlyIds`. It does not contain a recovered save or a live player world. Its SHA256/size are in `SOURCE_MANIFEST.json` under `derived_reference_files`.

The effective source registries include5 major paths/47 subpaths,681 arts,591 materials,225 registered starter recipes and12 separate living recipes. These are registry scopes;225 is not a claim that every recipe definition in the archive has been counted. Myriad extension arrays may already be merged into effective registries. Do not sum overlapping arrays as unique totals.

[Detailed audit](SOURCE_AUDIT_REPORT.md) records data-quality problems, source-stage versus track-ordinal differences, exact selected IDs and converter behavior. [Source analysis](../ROADMAP/SOURCE_GAME_ANALYSIS.md) gives the concise architecture/count interpretation. Source includes18 missing `MAT_FORM_*` ingredients in some recipes and inconsistent resource placement/effect bindings; it is not safe to bulk import every definition.

## First-stage migration records

- [migration/selected_raw.json](migration/selected_raw.json): exact selected original branch, art, material, recipe and environment records; retains source file/line provenance. The selection has3 canonical subpaths,9 arts,25 materials,8 recipes and4 environments. Eight recipes contain26 input references resolving to25 distinct source materials.
- [migration/mapping.json](migration/mapping.json): deterministic field/ID mapping, normalized target records and unsupported-effect decisions. Imported content IDs receive `SRC110_`; the3 canonical branch IDs stay unchanged.
- [tools/migrate_source.js](../tools/migrate_source.js): deterministic converter consuming the retained migration selection.
- [data/data_expansion.js](../data/data_expansion.js): adapted target data generated by that converter. Gameplay wiring and tests belong to the target modules and current QA, not the original source.

The target preserves XIAN9/BODY5/GOD4 parent stages and `HC.FINGERPRINT = 155:2f9c9dd7`; source5-path/47-track structures, source save envelopes and68-axis identity objects are not substituted. Source cooldowns, faith costs, `effectBindings`, inventory ownership and lifecycle wrappers require explicit target behavior. Unsupported source effects must remain recorded rather than silently invented.
