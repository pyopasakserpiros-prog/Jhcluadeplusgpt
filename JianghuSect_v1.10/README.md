## เปิดเล่น

- วิธีสะดวก: เปิด `JianghuSect_single.html` ในเบราว์เซอร์ที่รองรับ JavaScript (Chrome/Edge/Firefox/Safari)
- โครงการหลายไฟล์: เปิด `index.html` โดยเก็บโฟลเดอร์ `data/`, `js/`, `css/` ไว้ด้วยกัน หรือรัน `python3 -m http.server 8000` แล้วเปิด `http://localhost:8000`
- บน Android ให้ดาวน์โหลดไฟล์ HTML ลงเครื่องแล้วเปิดด้วยเบราว์เซอร์ หากแอปจัดการไฟล์เปิดเป็นข้อความ ให้เลือกเปิดด้วย Chrome หรือใช้โครงการผ่าน local web server
- เมนู → เกม → ส่งออกเซฟ เป็น JSON เพื่อสำรอง/ย้ายเบราว์เซอร์ การเปิดไฟล์จากตำแหน่งอื่นอาจมี localStorage คนละชุด ให้นำเข้าเซฟเอง

## มีอะไรใหม่

เพิ่มสายเซียนจันทราเหมันต์ กายาพฤกษาอมตะ และเทพโอสถโพธิญาณ พร้อม9วิชาที่มีรูปแบบต่อสู้ชัดเจน วัตถุดิบ25ชนิด สูตร8รายการ อสูร5ชนิด และพื้นที่4แห่ง เชื่อมกับการเดินทาง ผลิต บริจาค คลัง ร้านค้า และหอคัมภีร์เดิม

v1.10.1 เพิ่มตลาดพ่อค้าภายนอกแบบมีสต็อกและกระเป๋าหินวิญญาณจริง สำนักซื้อสินค้าที่ขาดตามความต้องการและทุนสำรอง ขายสินค้าส่วนเกินโดยคงคลังขั้นต่ำ ส่วนสมาชิกซื้อโอสถหรือขายวัตถุดิบ/โอสถพื้นฐานกับพ่อค้าโดยใช้หินวิญญาณส่วนตัว ธุรกรรมบันทึกและเซฟ/โหลดได้ แยกจากแต้มคุณูปการซึ่งยังใช้เฉพาะเศรษฐกิจภายในสำนัก

v1.10.2 เพิ่มวงจรม้วนตำรับส่วนตัว (`n.inv.recipes`) และการจูนสมดุลเศรษฐกิจหลายปี:
- การค้นพบตำรับในพื้นที่ใหม่จะสร้างม้วนตำรับจริง 1 ม้วน (ไม่ค้นพบซ้ำตราบที่มีม้วนตำรับนั้นอยู่ในโลก)
- สมาชิกที่พบม้วนตำรับสามารถเลือกส่งเข้าหอคัมภีร์ทันที หรือเก็บไว้ในกระเป๋าส่วนตัวเพื่อศึกษา คัดลอก (`CONTENT.copyRecipe`), ขายต่อเป็นหินวิญญาณ (`CONTENT.tradeRecipe`), หรือนำมาบริจาคภายหลัง (`CONTENT.donateRecipe`); การบริจาคตำรับซ้ำที่มีในหอคัมภีร์แล้วจะได้ `0` คป.
- สมาชิกที่จะผลิตตามตำรับที่ค้นพบในหอคัมภีร์ต้องมีระดับ/ตำแหน่งถึงเกณฑ์ (`CONTENT.canAuthorizeRecipe`) และจ่ายค่าธรรมเนียมขอสิทธิ์ศึกษาตำรับเพียงครั้งเดียว (`CONTENT.recipeFee`, `CONTENT.authorizeRecipe`)
- ปรับสมดุลการเสก/เผาแต้มคุณูปการ ดัชนีราคาตามระดับตบะและราคาจริง ป้องกันการซื้อแล้วบริจาคทำกำไร (arbitrage) และปรับการเลือกใบสั่งผลิตให้ครอบคลุมทั้ง 8 ตำรับใหม่

v1.10.3 เพิ่มระบบสายบำเพ็ญเฉพาะทางอิสระ (Independent Specialization Tracks) และการเปรียบเทียบพลังรบเชิงการทำงาน:
- นำเข้าลำดับ 9 ขั้นแท้จริงของสายเฉพาะทาง (เซียนจันทราเหมันต์, กายาพฤกษาวสันต์, เทพโอสถโพธิสัตว์) โดยไม่บีบอัดลำดับ 9 ขั้นลงเป็น 5 หรือ 4 ขั้นตามตำแหน่ง
- คงโครงสร้างขั้นหลักเดิมไว้ทั้งหมด (เซียน 9 ขั้น, กายา 5 ขั้น, เทพศรัทธา 4 ขั้น)
- เพิ่มระบบสถานะสายเฉพาะทางอิสระในตัวละคร (`c.track`): พัฒนาตบะคู่ขนานไปกับขั้นหลัก, มีเกณฑ์ทักษะและศิลาวิญญาณกำกับ, และระบบทะลวงขั้นอัตโนมัติ
- เพิ่มการจับคู่แถบพลังหลักแบบต่อเนื่อง (`majorPowerMapping`) และการคำนวณเปรียบเทียบพลังรบเชิงการทำงาน (`CULT.compareFunctionalPower`) พร้อมอัตราส่วน ความต่างขั้น และคำประเมินภาษาไทย

v1.10.4 เพิ่มรูปแบบวิชาต่อสู้เฉพาะทาง 4 รูปแบบ (หนุนทัพ `support`, บำบัด `heal`, อัญเชิญ `summon`, ร่ายต่อเนื่อง `channel`):
- หนุนทัพ (`support`): บัฟฝ่ายตนเองพร้อมกันทั้งทีม (`C.alliesOf`) มอบขวัญกำลังใจ (+15% พลังโจมตี) หรือรัศมีคุ้มกาย (+20% ป้องกัน)
- บำบัด (`heal`): ตรวจหาเพื่อนร่วมทีมที่เจ็บหนักที่สุด (`lowestAlly`) ฟื้นฟูพลังชีวิตและล้างสถานะผิดปกติร้ายแรงทั้งหมด
- อัญเชิญ (`summon`): สร้างร่างจำลอง/เทพอสูรเข้าร่วมรบจริง รับดาเมจและดึงดูดการโจมตีแทนผู้ใช้ สลายตัวเมื่อหมดเวลาหรือเลือดเหลือ 0
- ร่ายต่อเนื่อง (`channel`): ทำดาเมจสะสมต่อเนื่องทีละรอบและปิดฉากด้วยดาเมจระเบิดพลังรุนแรง พร้อมระบบขัดจังหวะเมื่อติดสถานะมึนงง/ผนึกวิชา หรือโดนดาเมจหนักเกิน 12%
- ปรับคำอธิบายจุดเด่น/จุดด้อยในระบบให้ตรงกับการคำนวณจริงแบบตัวต่อตัว

v1.10.6 เพิ่มระบบคำสั่งสำรองคลังและนโยบายสวัสดิการการจัดสรรทรัพยากร:
- คำสั่งสำรองคลัง (`W.sect.reserveDirectives`) ควบคุมเกณฑ์สำรองข้าวสารขั้นต่ำ (วัน), อาหารปรุงเสร็จ, เกณฑ์ความปลอดภัยสำหรับการออกเดินทาง และสำรองโอสถฉุกเฉิน
- คำสั่งจัดการของขาดแคลน (`W.sect.shortageDirectives`) รวบรวมความต้องการเสบียงคลัง, โอสถฉุกเฉิน, วัตถุดิบตำรับการผลิต และโอสถทะลวงขั้น พร้อมเชื่อมต่อเข้ากับรายการสั่งซื้อของคาราวาน (`buyList`) และตลาดภายนอก
- พัฒนาระบบตัดสินใจแจกสวัสดิการ (`CPE.welfareDaily`) และจัดสรรอุปกรณ์ (`SIM.distributeGear`) ชั่งน้ำหนักความชอบธรรม/จำเป็นจริง (`meritocracy`) กับสายสัมพันธ์ (`relation bias`) โดยผู้ที่จำเป็นแต่ถูกข้ามเพราะการเล่นพรรคเล่นพวกจะเกิดความไม่พอใจ (อารมณ์/ความพึงพอใจลดลง บันทึกความรู้สึกไม่เป็นธรรม)
- ปกป้องโอสถและอุปกรณ์พรีเมียมจากการแจกฟรี แต่เปิดให้สมาชิกแลกซื้อได้ด้วยแต้มคุณูปการ (คป.) ในร้านค้าสำนัก

v1.10.7 ยกระดับประสิทธิภาพการประมวลผลบนเบราว์เซอร์และมือถือ (Priority P2):
- ปรับแต่ง Hot Path ของการจำลอง (`SIM.tick`, `AI.needs`, `AI.decide`, `AI.compat`, `STATS.get`, `MAP.findPath`, `U.MinHeap`, `ECO.inputsOk`) และการวาดภาพ Canvas (`measureCached`) โดยรักษาความถูกต้องเชิงกำหนด (Determinism) 100% และไม่แตะต้อง `js/human_core.js` (ล็อก `155:2f9c9dd7`)
- รองรับประชากรขนาดใหญ่ 80–100+ คนที่ความเร็วสูงสุด `48×` ได้อย่างลื่นไหล (`~1.20 ms/tick` หรือรองรับได้มากกว่า `800 ticks/s` / `200×`)
- ปรับปรุง UI และการสัมผัสบนหน้าจอมือถือ (`360×800`, `412×860`) และเดสก์ท็อป (`1280×800`) แก้ปัญหาแถบแจ้งเตือนบังมินิแมป การแตะลานสำนักเพื่อยกเลิกการเลือก และการซูมสองนิ้ว

v1.10.8 เพิ่มวิถีบำเพ็ญหลักใหม่ 2 วิถีอย่างสมบูรณ์ (วิถีมารอสูร `DEMON` 9 ขั้น และวิถีจิต·เซน `HEART_SOUL` 9 ขั้น) พร้อม 8 สายย่อย ลำดับขั้นเฉพาะทางอิสระ 9 ขั้นครบทุกสาย คัมภีร์หลัก 14 เล่ม วิชาต่อสู้ 45 วิชา โอสถทะลวงคอขวด 16 สูตร สมบัติด่านใหญ่ 12 ชิ้น และกลไกความเสี่ยง/ต้นทุนการฝึกเฉพาะทาง (มารอสูรเปลี่ยนจิตมารเป็นพลังตบะ ทนพิษสูง ดูดเลือดและสูบตบะเมื่อสังหาร เสี่ยงปราณมารย้อนกลับ; จิต·เซนเน้นปัญญาและสมาธิ ชำระจิตมารขณะบำเพ็ญ สะท้อนดาเมจและขัดเกลาจิตจากการประลอง เสี่ยงทะเลจิตร้าวฉาน)

v1.10.9 ปิดท้ายโร้ดแมปครบทุกหัวข้อ (Priority P3 — อวัยวะอสูรกลายพันธุ์ การทดลองคุณสมบัติ และการเมืองยุทธภพ):
- อวัยวะอสูรกลายพันธุ์ 10 ชนิด (`D.rareOrgans`): ชำแหละจากอสูรประจำถิ่นตามทักษะเอาตัวรอด/การแพทย์/ความปราณีต นำไปหลอมสกัดชุบชีพจร (`CONTENT.refineOrgan`) หรือใช้เป็นตัวเร่งปฏิกิริยาในการวิจัยตำรับ
- การทดลองคุณสมบัติ 8 โครงการ (`D.experiments`): ใช้สมุนไพร/แร่จริงและศิลาวิญญาณวิเคราะห์คุณสมบัติ (`propertyTags`) ค้นพบสูตรประยุกต์ที่ปลดล็อกตำรับพร้อมมอบโบนัสคุณภาพและผลผลิตถาวรให้การหลอมโอสถ/ตีเหล็ก
- ขั้วอำนาจและการเมืองยุทธภพ 6 สำนักใหญ่ (`D.factions`): ระบบสนธิสัญญา (`สัญญาการค้าข้ามสำนัก`, `สนธิสัญญาไม่รุกราน`, `พันธมิตรยุทธภพ`, `คว่ำบาตร`) ขบวนส่งทรัพยากรพิเศษทุก 10 วัน กำลังหนุนพันธมิตรยามศึกบุก และเหตุการณ์การเมืองยุทธภพ

ไปที่ **ยุทธภพ → 🌿 พื้นที่/ตำรับ** เพื่อดูทรัพยากร ความเสี่ยง สูตรที่รู้แล้ว ผู้ถือม้วนตำรับ ค่าสิทธิ์ศึกษา และคัมภีร์

คงความเร็ว0/1/2/4/8/16/32/48× การค้างของเฟรมไม่ตัดเวลาจำลองที่รอประมวลผล มีป้าย⏳แสดงงานค้าง ความเร็วจริงขึ้นกับอุปกรณ์และจำนวนNPC; ยังไม่มีผลทดสอบบน Snapdragon8Elite

## เซฟและขอบเขต

รับเซฟv1.9ที่มี Human Core `155:2f9c9dd7` และรักษาโครงสร้างเดิม เพิ่ม metadata สูตร/พื้นที่/ใบรับผลิต/เวลาค้าง ไม่มีการแปลงเซฟจากเกมต้นทางv2.08.3 แนะนำสำรองเซฟก่อนอัปเกรด เซฟv1.10ไม่รองรับการย้อนเปิดในเกมรุ่นเก่า

แพตช์นี้รองรับลำดับเก้าขั้นเฉพาะสายแท้จริงอย่างเป็นอิสระ โดยมีสถานะสายเฉพาะทาง เกณฑ์ทักษะและศิลาวิญญาณกำกับ พร้อมการเทียบพลังรบเชิงการทำงานโดยไม่ต้องบีบ 9 ขั้นลงเป็น 5 หรือ 4 ขั้น ตบะหลักของเกมนี้ยังคงเป็นเซียน9/กาย5/เทพ4ตามฐานเดิมเพื่อความเข้ากันได้ย้อนหลัง 100%

## โครงสร้างและคำสั่ง

- `data/data_expansion.js` — ข้อมูลที่แปลงแล้ว โหลดเพิ่มจากทะเบียนเดิม
- `js/content.js` — เชื่อมพื้นที่ การค้นพบ วงจรม้วนตำรับส่วนตัว ค่าสิทธิ์ศึกษา ผลตอบแทน และยาเข้ากับเอนจินเดิม
- `js/external_market.js` — ผู้มาเยือน สต็อกพ่อค้า การซื้อขายด้วยหินวิญญาณ และบันทึกธุรกรรม
- `ROADMAP/README.md` — สถานะ งานต่อ สถาปัตยกรรม ข้อจำกัด และผลทดสอบ
- `SOURCE_REFERENCE/README.md` — ไฟล์ต้นทางเดิม แคตตาล็อก ที่มา และตัวแปลง สำหรับพัฒนาต่อโดยไม่ต้องขอZIPต้นทางอีก
- `test/` — การทดสอบNode (25 กลุ่มทดสอบ) และสคริปต์Playwrightเดิม

```bash
node test/run_all.js
node tools/migrate_source.js
node tools/build_single.js
node test/long_simulation.js my-seed 360 test/results/my-seed.json
```
