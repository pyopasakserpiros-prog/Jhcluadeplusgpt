# v1.10 first-stage implementation plan

User directive authorizes autonomous implementation and selection; no design approval gate needed.

## Decision
Extend the current classic-script global registries and W simulation. Do not embed a second engine. Keep Human Core byte-identical. Preserve XIAN 9, BODY 5, GOD 4 ranks. Source's independent 6–11-rank tracks are reference-only, not equivalent ordinals. Add three supported source specializations, a small set of explicit combat profiles, selected dependency-complete recipes/materials, and four renewable region ecosystems. Discoveries gate imported manuals/formulas; basic welfare recipes stay accessible.

## Alternatives considered
- Bulk merge: rejected because five source paths, side-track ranks, effect bindings, world scale and inventories conflict.
- Database-only import: rejected because it would not connect resource scarcity, crafting, discovery, NPC choice and contribution purchasing.
- Native selective vertical slice: chosen by engineer within user authorization; modest content with real transactions, destinations and UI.
