> ค่านี้ถูกตรวจ 2 จุด: (1) `test/core_lock.js` ล้มทันทีหากนิยามมิติเปลี่ยน (2) ไฟล์เซฟเก็บค่านี้ไว้ และโหลดไม่ได้ถ้าไม่ตรง ดังนั้นหากแก้นิยามมิติใด ๆ ค่าจะไม่ตรง — เวอร์ชันถัดไปต้อง **เพิ่มชั้นใหม่** เท่านั้น ห้ามแก้/ลบ/เปลี่ยนความหมายมิติเดิม

## 1. หลักการวัดตัวตนของ NPC

NPC หนึ่งคนคือเวกเตอร์ **155 มิติ** ในสเกล 0–100 (ยกเว้นบางค่าที่อธิบายไว้) แบ่งเป็น 10 ชั้น

- **ค่ากำเนิด (innate)** เก็บใน `npc.h.innate` — สุ่มจากปัจจัยแฝง (พันธุกรรม ตระกูล ชาติกำเนิด รากวิญญาณ ลักษณะพิเศษ) ตอนสร้างตัวละคร **แล้วไม่เปลี่ยนอีก**
- **ค่าฐาน (raw)** `npc.h.<ชั้น>.<รหัส>` เริ่มจากค่ากำเนิด และขยับช้า ๆ จากการฝึก (`HC.trainBody/trainMind/practice`) และประสบการณ์ชีวิตที่มีความหมาย (`HC.experience`)
- **ค่าปัจจุบัน (effective)** = `HC.eff(npc, path)` = (ค่าฐาน + ตัวบวกจากลักษณะพิเศษ/บาดแผล) × ตัวคูณ แล้วคูณเส้นโค้งอายุ (เฉพาะกายภาพ/ปัญญา; ปัญญาญาณเพิ่มตามวัย) แล้วตัดให้อยู่ใน 0–100
- **สถานะชั่วขณะ (state)** เช่น พลังชีวิต อิ่ม พักผ่อน อารมณ์ เครียด อยู่แยกจากแกน ไม่ถือเป็นตัวตน
- **ความต่างระหว่างคน** = `HC.compare(A,B)` ใช้ระยะห่างแบบถ่วงน้ำหนักบน z-score ของทุกมิติ → ได้ % ความคล้าย, มิติที่ต่างที่สุด/คล้ายที่สุด และความต่างรายชั้น
- **การตัดสินใจ** ของ NPC ในเกมอ่านค่าจากแกนเท่านั้น (บุคลิก 14 → วิธีเลือก, คุณค่า 8 → สิ่งที่อยากได้, ความสนใจ → เลือกกิจกรรม, กาย/ปัญญา → ผลลัพธ์จริง) จึงไม่มีสคริปต์ตายตัว

### ป้ายระดับ (HC.levelLabel)
- ≥96 : เหนือมนุษย์
- ≥86 : เลิศล้ำ
- ≥71 : สูง
- ≥56 : ดี
- ≥45 : เฉลี่ย
- ≥30 : ต่ำกว่าเฉลี่ย
- ≥15 : ต่ำ
- ≥0 : ต่ำมาก
