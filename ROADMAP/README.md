# เริ่มพัฒนาต่อจากแพ็กเดียว

1. อ่าน `CURRENT_STATUS.md` เพื่อรู้ว่าอะไรทำแล้ว/ยังไม่ทำ
2. อ่าน `ARCHITECTURE.md` และ `DATA_MIGRATION_MAP.md` ก่อนแตะเอนจิน/เซฟ
3. อ่าน `CONTENT_CATALOG.md` เพื่อหาIDsและแหล่งทรัพยากร
4. เลือกงานจาก `ROADMAP.md` โดยทำตามdependencyและacceptance criteria
5. รัน `TESTING_AND_VALIDATION.md` แล้วตรวจข้อจำกัดใน `DECISIONS_AND_KNOWN_ISSUES.md`
6. หากต้องดึงเนื้อหาต่อ ใช้ `../SOURCE_REFERENCE/` โดยตรง ไม่ต้องขอเกมต้นทางใหม่

ไฟล์เก่าใน `../docs/` และ `../README_TH.md` เก็บไว้เป็นประวัติฐานเกม ข้อมูลสถานะรุ่นปัจจุบันอยู่ที่นี่
