# แผนพัฒนา — 2.06 Sect Store, Workshop Labor & Living Economic Ecosystem

## ส่งมอบในแพตช์นี้

- [x] แยก **คลังสำนัก (`คลังสำนัก`)** ออกจาก **ร้านค้าสำนัก (`ร้านค้าสำนัก`)**: ของที่ศิษย์หามาจากข้างนอกหรือหลอมให้สำนักจะเข้าคลังสำนักก่อน ผู้อาวุโสฝ่ายคลังหรือเจ้าสำนักจึงคัดแยกขึ้นร้านค้าสำนัก (`curateStore`, `transferToStore`, `returnToTreasury`) พร้อมสำรองของแจกฟรีพื้นฐาน (`GRANT`) และวัตถุดิบสำหรับโรงหลอมไว้ในคลังสำนัก
- [x] ระบบไร้การเสกของจากอากาศ (`Zero Thin-Air Provenance`): สินค้าทุกชิ้นในร้านค้าสำนักและคลังสำนักต้องมาจากศิษย์ที่เก็บสมุนไพร ล่าอสูร สำรวจวาสนา บริจาคของส่วนตัว หรือหลอมสร้างจริง พร้อมบันทึกชื่อผู้จัดหา/ผู้หลอม
- [x] การหลอมโอสถและศาสตรา 2 โหมด: **โหมด A หลอมให้สำนัก (`craftForSect` / `sectCraft`)** ใช้วัตถุดิบของคลังสำนัก ไม่เสียของส่วนตัว ได้แต้มคุณูปการ และของเป็นของสำนัก; **โหมด B หลอมใช้เอง (`makePersonalItem`)** ใช้วัตถุดิบส่วนตัว ของเป็นของศิษย์เอง จะเก็บใช้หรือบริจาคแลกแต้มก็ได้
- [x] ตำรับโอสถและศาสตราพื้นฐานของสำนักเปิดให้ศิษย์เรียนฟรีทุกคน (`ensureBasicSectRecipes`) ส่วนตำรับขั้นสูงขึ้นอยู่กับวาสนาการค้นพบ (`tryFortuitousRecipeDiscovery`) หรือการวิจัยของศิษย์แต่ละคน
- [x] ระบบราคาตามระดับ (`T1–T7`), สีคุณภาพ และประเภทสินค้า (`MATERIAL < PILL < SCROLL < EQUIPMENT`): วัตถุดิบสีม่วงถูกกว่าโอสถและศาสตราสีม่วงที่คราฟเสร็จแล้วในระดับเดียวกันเสมอ และของคราฟเสร็จแล้วมีมูลค่าสูงกว่าผลรวมวัตถุดิบตั้งต้นทุกสูตร
- [x] วงล้อเศรษฐกิจสำนักมีชีวิต (`Demand & Supply Economic Flywheel`) และปันผลผู้จัดหา/ผู้หลอม (`Creator Royalty +12%`) พร้อมชุดทดสอบใหม่ `tests/sect_store_ecosystem_v206.cjs` (รวม 37 กลุ่มทดสอบ)

- [ ] เพิ่มพฤติกรรมเชิงพื้นที่ให้ต่างกันชัดเจน เช่น หลบคน หวงถิ่น ถอยเมื่อบาดเจ็บ และปกป้องลูก

- [x] ใช้เพดานประชากรและเวลาฟื้นต่อ habitat; วัตถุดิบดรอปผูกกับกายวิภาคของชนิดอสูรและทะเบียนวัตถุดิบ

- [x] ระบบ habitat spawner แยกจากอีเวนต์สัตว์อสูรบุก; การเกิดตามถิ่นไม่ใช่เหตุการณ์บุก
- [ ] ขยาย QA เรื่องการเก็บซากซ้ำ/การบันทึกที่มาและ replay ระยะยาวในหลายสถานการณ์

**ตรวจรับ:** เดินถึงทุกแหล่งได้, ภาพและการคลิกตรงกัน, จำนวนอสูรไม่เกิน cap, save/load/replay ตรงกัน, การเก็บซากซ้ำไม่เพิ่มของ, ไม่มีอสูรระดับสูงหลุดเข้ามาใน pool ปกติ

### B. โอสถพื้นฐานมีคุณค่าในชีวิตประจำวัน

- [ ] ตรวจแหล่งฟื้น HP/ความเหนื่อย/อาการปวดทุกทาง ไม่ใช่แก้ค่าเพียงจุดเดียว: พักต่อเนื่อง พักจบงาน รักษาด้วยสมุนไพรดิบ อาหาร ถอยถึงที่ปลอดภัย วิชาและวาสนา
- [ ] ลดความเร็วฟื้นตามธรรมชาติอย่างสมดุล; ยังมีทางพักปลอดภัยที่ค่อย ๆ ฟื้นได้โดยไม่มียา ห้ามทำให้สำนักใหม่ติดทางตัน
- [ ] ตรวจความสัมพันธ์ `currentQiV190`, `stageLocal.combatState.qi`, และความก้าวหน้าบ่มเพาะ ให้โอสถคืนปราณเติมแหล่งปราณที่ระบบต่อสู้ใช้จริง และไม่เพิ่มตบะโดยชื่อพ้อง
- [x] เพิ่มตำรับส่วนกลาง 11 สูตรและสูตรวิจัยส่วนบุคคล 4 แบบ โดยใช้วัตถุดิบใหม่ร่วมกับวัตถุดิบเดิมและเงื่อนไขทักษะ/สถานที่ของระบบผลิต
- [ ] ตรวจสมดุลสูตรพื้นฐานทั้งระบบให้คนเริ่มต้นมีทางเลือกผลิต/ใช้ยาได้ โดยไม่ติดเงื่อนไขความสามารถสูงเกินไป
- [ ] ตัวอย่าง: สมานแผล คืนปราณ แก้เหนื่อย ถอนพิษ ยาทาลดปวด ชาสงบใจ ชำระพิษโอสถ และน้ำแกงเดินทาง สูตรสุดท้ายปรับตามระบบจริงได้
- [x] สูตรใหม่ใช้ชิ้นส่วนอสูร/สมุนไพร/แร่ร่วมกับวัตถุดิบเดิม; ทุกวัสดุใหม่ถูกตรวจว่ามีผู้ใช้ในทะเบียนสูตรอย่างน้อยหนึ่งสูตร
- [ ] ปรับสมดุลเส้นทางวัตถุดิบพืชล้วนให้ผู้เล่นเริ่มผลิตได้โดยไม่ต้องพึ่งการล่าอสูร
- [ ] ฝีมือ/ความรู้/เครื่องมือ/คุณภาพวัตถุดิบกำหนดความบริสุทธิ์และโอกาสสำเร็จ; แยกความบริสุทธิ์ออกจาก tier สูตร และไม่เพิ่มค่าสถานะกำเนิดให้ผ่านเงื่อนไข
- [ ] ใช้วัตถุดิบ เวลา ผลิตภัณฑ์และ provenance จริง; ยามีการใช้แล้วหมด ผลขึ้นกับความบริสุทธิ์ และการใช้ซ้ำ/พิษสะสมสมเหตุผล
- [ ] ให้ NPC บาดเจ็บหนักยังพิจารณาใช้ยาหรือขอยาได้ ตรวจ health/danger gates ของ options เดิมที่อาจตัดตัวเลือกยาทิ้ง
- [ ] ให้ NPC ผลิต เก็บสำรอง เบิก แบ่ง และใช้ยาตามอาการและความเสี่ยงจริง ผ่าน scorer และ ledger เดิม ห้ามสร้างยาให้เองในตัวเลือก AI

**ตรวจรับ:** ล่า/เก็บพืช → ส่งวัตถุดิบ → ผลิต → โอสถเข้าบัญชี → ใช้ในชีวิตประจำวันครบวงจรได้เอง; ดูจำนวนก่อน/หลังและผลต่อ HP/ปราณได้; มือใหม่ทดลองผลิตได้; ยาต่างความบริสุทธิ์มีผลต่างจริง; ไม่มียาฟรีหรือฟื้นลัดจนยาหมดคุณค่า

### C. สมุนไพรป่า เมล็ด และการจัดสวน

- [x] เพิ่มสมุนไพรใหม่ 4 ชนิด เมล็ด และ crop ที่ใช้ระบบสวนเดิม; สมุนไพรและแร่ใหม่มี resource node จริง
- [ ] เพิ่มพืชป่าเพิ่มเติมและปรับสัดส่วนการเกิด/อัตราฟื้นตัวตามความขาดแคลนในระบบผลิต
- [ ] เมล็ดระดับต่ำ กลาง สูง และตำนาน มีที่มาจริง; ระดับสูง/ตำนานมาจากเนื้อหาหายาก แยกจากการแจกทั่วไป และมีสถานที่/เงื่อนไขปลูกที่ต้องตรวจจริง
- [ ] สวนเริ่มต้นราว 8–12 แปลงตามสมดุล: เตรียมดิน ลงเมล็ด งอก โต สุก เก็บเกี่ยว พร้อมความชื้น การดูแล ความอุดมสมบูรณ์และเมล็ดคืนอย่างยั่งยืน
- [ ] การปลูก/รดน้ำ/เก็บเกี่ยวของ NPC ต้องเดินถึง ใช้เวลา และจองงาน; เคลียร์การจองเมื่อยกเลิก ตาย ออกนอกแผนที่ หรือสวนถูกทำลาย
- [ ] คิดมูลค่า **ต่อพื้นที่และเวลา** จากความขาดแคลนวัตถุดิบ ยาสำรอง ความต้องการใช้ประจำ ระยะโต ความเสี่ยงและฝีมือ ไม่ใช่เลือกระดับหายากที่สุดเสมอ
- [ ] เมล็ดตำนานไม่แย่งพื้นที่พืชสามัญจนยาพื้นฐานขาด; ข้อเสนอสำรองอย่างน้อย 60% ของแปลงที่รองรับสำหรับพืชใช้ประจำจนเสบียงถึงเป้า
- [ ] หน้าสวนแสดงความต้องการ เหตุผลที่เลือกพืช งานที่จอง ผลผลิตและเมล็ด ให้ตรวจการตัดสินใจได้

**ตรวจรับ:** สวนไม่ว่างทั้งที่มีเมล็ดและแรงงานพร้อม; ไม่เบิกเมล็ดซ้ำหรือเก็บผลซ้ำ; พืชสามัญยังปลูกเมื่อมีเมล็ดตำนาน; ทุกสูตรพื้นฐานมีเส้นทางได้วัตถุดิบที่ทำซ้ำได้; คนหลายคนไม่ทำงานแปลงเดียวจนของเพิ่มซ้ำ

### D. เหตุการณ์หลังวงจรหลักมั่นคง

- [ ] สัตว์อสูรบุกแบบ event, การย้ายถิ่น, ฤดูสมุนไพรผลิบาน, ภัยแล้ง/ศัตรูพืช, พ่อค้าเมล็ด, โอกาสได้เมล็ดหายาก
- [ ] ทุกเหตุการณ์มี trigger, cooldown/deadline, source และผลจริง; แยก one-shot/ซ้ำได้ และแยกจาก resource spawner ปกติ
- [ ] เชื่อมกับสายเหตุการณ์และชีวิต NPC ที่วางไว้เดิมด้านล่าง โดยไม่เพิ่มแกนตัวตนมนุษย์ชุดใหม่
